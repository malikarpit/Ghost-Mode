## Reporting a Vulnerability

Security is a core priority for Ghost Mode. Because Ghost Mode interacts with low-level macOS power management (`pmset`) and system permissions, we take all vulnerability reports seriously.

If you discover a security vulnerability:

1. **Do not create a public issue.**
2. Please use GitHub's **Private Vulnerability Reporting** feature under the **Security** tab of this repository, or email the maintainer directly via GitHub profile.
3. Include detailed steps to reproduce the vulnerability.

### What to expect:
- Acknowledgement of receipt within 48 hours.
- A thorough investigation and assessment.
- A coordinated fix and public release advisory.
